# Data Dictionary: Financial Market Risk & Portfolio Analysis

## 1. Introduction

This document describes the principal datasets generated and used in the Financial Market Risk & Portfolio Analysis project.

It explains the meaning of common variables, financial metrics, and portfolio identifiers to make the datasets easier to interpret and reproduce.

The project uses historical adjusted stock prices, calculated returns, portfolio weights, and performance statistics.

## 4. Historical Analysis Datasets

### 4.1 Volatility Summary

**File:** `volatility_summary.csv`

Contains historical volatility estimates for the selected assets.

| Metric | Description |
|---|---|
| Asset | Asset ticker. |
| Annualized Volatility | Estimated annualised standard deviation of daily returns. |

### 4.2 Correlation Matrix

**File:** `correlation_matrix.csv`

Contains pairwise correlation coefficients between asset returns.

Each matrix entry represents the correlation between the asset identified by its row and the asset identified by its column.

Correlation values range from -1 to +1.

### 4.3 Performance Summary

**File:** `performance_summary.csv`

Contains historical performance and risk statistics.

Common metrics include:

| Metric | Description |
|---|---|
| Annualized Return | Average daily arithmetic return multiplied by 252. |
| Annualized Volatility | Daily standard deviation multiplied by the square root of 252. |
| Sharpe Ratio | Annualised excess return divided by annualised volatility, using the stated risk-free rate assumption. |
| Maximum Drawdown | Largest observed percentage decline from a previous wealth peak. |
| CAGR | Compound annual growth rate over the evaluation period. |

## 5. Portfolio Analysis Datasets

### 5.1 Cumulative Wealth

**File:** `cumulative_wealth.csv`

Contains the growth of an initial investment over time.

| Field | Description |
|---|---|
| Date | Trading date. |
| Portfolio columns | Cumulative wealth values for the corresponding portfolios or benchmark. |

Cumulative wealth represents the value of an initial investment after applying the sequence of portfolio returns.

### 5.2 Drawdowns

**File:** `drawdowns.csv`

Contains the percentage decline in portfolio wealth relative to its previous running maximum.

| Field | Description |
|---|---|
| Date | Trading date. |
| Portfolio columns | Drawdown values for the corresponding portfolios or benchmark. |

Drawdown values are generally zero or negative. More negative values indicate larger declines from previous wealth peaks.

### 5.3 Monthly-Rebalanced Returns

**File:** `monthly_rebalanced_returns.csv`

Contains portfolio return observations generated by the final monthly-rebalanced backtest.

| Field | Description |
|---|---|
| Date | Trading date. |
| Portfolio columns | Daily returns for the corresponding portfolio strategies and benchmark. |

### 5.4 Monthly-Rebalanced Weights

**File:** `monthly_rebalanced_weights.csv`

Contains the asset allocation weights used by the portfolio strategies.

| Field | Description |
|---|---|
| Date | Date associated with the portfolio allocation. |
| Asset columns | Portfolio allocation assigned to each asset. |
| Portfolio identifier, where present | Identifies the strategy associated with the allocation. |

Portfolio weights represent the proportion of portfolio capital allocated to each asset. The sum of the target weights for each portfolio should equal 1, subject to numerical precision.

### 5.5 Monthly-Rebalanced Comparison

**File:** `monthly_rebalanced_comparison.csv`

Contains the final out-of-sample performance comparison.

| Metric | Description |
|---|---|
| Portfolio | Portfolio strategy or benchmark. |
| Annualized Return | Annualised arithmetic return. |
| Annualized Volatility | Annualised standard deviation of daily returns. |
| Sharpe Ratio | Risk-adjusted return measure. |
| Maximum Drawdown | Largest peak-to-trough percentage decline. |
| CAGR | Compound annual growth rate. |

This dataset is the source of the final portfolio performance comparison presented in the project README and research report.

## 6. Financial Terminology

| Term | Meaning |
|---|---|
| Adjusted Close | Closing price adjusted for relevant corporate actions, such as dividends and stock splits. |
| Daily Return | Percentage change in adjusted price from one trading day to the next. |
| Volatility | Statistical measure of return variability. |
| Covariance | Measure of how two asset returns vary together. |
| Correlation | Standardised measure of the linear relationship between two variables. |
| Portfolio Weight | Proportion of portfolio capital allocated to an asset. |
| Rebalancing | Adjusting portfolio holdings to restore target allocations. |
| Turnover | Measure of the amount of portfolio trading required to change allocations. |
| Basis Point (bps) | One-hundredth of one percentage point; 100 basis points equal 1%. |
| Out-of-Sample Testing | Evaluating a strategy on data not used in its initial parameter estimation. |
| Benchmark | Reference investment used to evaluate portfolio performance. |

## 7. Data Interpretation Notes

1. Returns are expressed as decimal values in the underlying datasets unless otherwise specified. For example, 0.05 represents a 5% return.
2. Portfolio weights are generally expressed as decimal proportions. For example, 0.20 represents a 20% allocation.
3. Correlation coefficients range from -1 to +1.
4. Volatility and return values may be expressed as decimals or percentages depending on the output file.
5. Dates refer to trading observations rather than calendar-day observations.
6. The final out-of-sample portfolio comparison uses monthly rebalancing.

## 8. Documentation Note

This dictionary describes the principal datasets and common variables used in the project. Individual CSV files may contain additional columns or use different column labels depending on the analysis script that generated them.

The actual CSV headers should be consulted when interpreting or reproducing individual analyses.
