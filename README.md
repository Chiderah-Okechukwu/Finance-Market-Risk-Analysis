# Financial Market Risk & Portfolio Analysis

## Project Overview

This project investigates the relationship between
investment returns and financial risk using historical
stock market data.

## Objectives

- Analyse historical stock price movements.
- Calculate daily and cumulative returns.
- Measure investment volatility.
- Examine correlations between financial assets.
- Evaluate portfolio diversification.
- Compare portfolio risk and return.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- JupyterLab
- Git and GitHub

## Project Structure

- data/: Financial datasets
- notebooks/: Exploratory analysis
- src/: Reusable Python scripts
- reports/: Research findings and visualisations
